# Power BI Reports

Folder này chứa các báo cáo Power BI cho dự án US Accidents Data Warehouse.

## Nội dung:

- Power BI Desktop files (.pbix)
- Data models
- Visualizations & dashboards
- Reports & analytics

## Hướng dẫn:

1. Mở file `.pbix` bằng Power BI Desktop
2. Kết nối đến SSAS Cube hoặc SQL Server
3. Refresh data nếu cần
4. Xem các dashboard và reports
